# CodeAlpha Task 3: Data Visualization

## Project Overview
This project focuses on analyzing and visualizing student performance using Python. The Students Performance in Exams dataset is used to explore marks in Mathematics, Reading, and Writing.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Kaggle Notebook

## Visualizations Created
1. Bar Chart – Average Maths Score by Gender.
2. Pie Chart – Gender Distribution.
3. Histogram – Distribution of Maths Scores.
4. Box Plot – Comparison of Subject Scores.
5. Correlation Heatmap – Relationship Between Subject Scores.
6. Scatter Plot – Maths Score vs Reading Score.

## Key Insights
- Compared average Maths scores by gender.
- Examined the gender distribution of students.
- Explored the distribution of Maths scores.
- Compared marks across three subjects.
- Identified relationships between subject scores.

## Dataset
Students Performance in Exams dataset.

## Conclusion
This project demonstrates how data visualization helps identify patterns, compare student performance, and understand relationships between different subjects.
